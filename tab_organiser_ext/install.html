Install the Tab Organiser extension

Adds the Open … in Chrome buttons to chrome_report_v1.4.html reports — for windows and for single tab groups.

What it does

Report pages can always open a window or a group in a second browser window; that needs nothing extra. The extension is what turns those into real Chrome windows containing real Chrome tab groups, with each group's title and colour preserved.

It only ever creates new tabs. It never moves, closes or reorders anything in your existing windows.

Install (once)

  1. Open chrome://extensions in Chrome.
  2. Switch on Developer mode (top right of that page).
  3. Click Load unpacked and pick the tab_organiser_ext folder — the one containing manifest.json.
  4. Open the extension's Details page and switch on Allow access to file URLs. Reports are opened as file:// pages, so without this the extension cannot see them.

Chrome will not let this page link straight to chrome://extensions

Chrome blocks navigation to chrome:// URLs from web and file:// pages, so a link here would do nothing. Type or paste the address below instead.

chrome://extensions

Check it works

  1. Reopen the report. The badge at the top right of the report turns green and reads extension connected. Until then the Chrome-side buttons stay disabled; the plain grouped popups keep working.
  2. Open selftest.html from this folder. It runs a handful of real API calls and prints PASS or FAIL for each.

The self-test opens a few example.com tabs in new windows; close them when you are done. It does not touch your existing windows.

Permissions, and why

  • tabs, tabGroups, windows — read and create tabs, create groups with their titles and colours, and create the target windows.
  • Host access to file:///*, localhost and 127.0.0.1 — report pages only.

No network access, no storage, no background script, no telemetry.

chrome_tab_organiser

Two Python tools (standard library only — no installs): chrome_report_v1.1.py generates an HTML report of your open Chrome tabs by tab group, and chrome_report_edit_v1.3.py is a local web app for editing that report.

1  Requirements

  • Python: version 3, plus the two files chrome_report_v1.1.py and chrome_report_edit_v1.3.py in the same folder.
  • No Python? Use the pre-built executables chrome_report_v1.1.exe and chrome_report_edit_v1.3.exe (same folder) instead — same commands, no install needed.
  • Chrome needs to have logged-in/session data in its Default profile on this machine.

2  Generate the report

python chrome_report_v1.1.py                  # -> chrome_tabs_Default_v1.1.html
chrome_report_v1.1.exe                        # same, no Python needed (double-click works)
python chrome_report_v1.1.py --json --outdir reports   # also JSON, into .\reports
  • Chrome may keep running — the report is read from its session files on disk.
  • --data-dir PATH — non-standard Chrome data directory.
  • If a warning: skipped (... in use by Chrome) appears, wait a few seconds and re-run.

3  Run the editor

python chrome_report_edit_v1.3.py --dir reports   # browser opens at http://127.0.0.1:8765/
chrome_report_edit_v1.3.exe --dir reports         # same, no Python needed
  • --dir PATH folder of *.html reports to manage (default: the script’s folder).
  • --port N / --host ADDR — default 8765 / 127.0.0.1. Use --port 9000 if 8765 is busy.
  • --no-browser — print the URL instead of auto-opening.
  • Stop the server with Ctrl+C in the terminal.

4  Editor options at a glance

ControlWhat it does
Dropdown + LoadPick a report from the managed folder and load it.
Open…Load any .html report file from anywhere.
Click a tab title, URL, group chip or “Window N” headingRename it in place. Editing a URL also updates the link; clearing a group name ungroups the tab.
+ on a row / Add tab in a window headerInsert a tab after that row / at the end of the window. Dialog asks: Window, Position, Group (optional), Tab name, URL.
× on a rowDelete that tab. (Ctrl+Backspace also works while a row is focused.)
“sort groups alphabetically” tick-boxRearrange the current report: within each window, ungrouped rows first, then tab groups A–Z (case-insensitive). Untick → restores the previous order. Inserting while sorted keeps the row where you placed it.
Name box + SaveWrite the report to disk under that *.html name (Enter also saves). Nothing is saved until you press Save.

5  One-minute workflow

python chrome_report_v1.1.py --outdir reports
python chrome_report_edit_v1.3.py --dir reports
# Load chrome_tabs_Default_v1.1.html - rename / insert / delete / tick the sort box as you like
# type a new name, press Save -> reports/<name>.html
Remember: reports always load in their original order — the sort tick-box never runs by itself. Opening a new report resets it.
